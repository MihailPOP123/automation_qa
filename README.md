# Automation QA Portfolio Project

## Описание

Это проект по разработке автоматических тестов в браузере. Главная цель данного репозитория — продемонстрировать мои навыки в области автоматизации тестирования (QA Automation), умение выстраивать правильную архитектуру тестового фреймворка и работать с современными инструментами.

## Стек технологий

* **Язык программирования:** Python (>=3.13)

* **Фреймворк для тестирования:** Pytest

* **Автоматизация браузера:** Selenium WebDriver + Webdriver Manager

* **Генерация тестовых данных:** Faker

* **Управление зависимостями:** Poetry

##  Структура проекта

Проект спроектирован с использованием паттерна **Page Object Model (POM)** для удобства поддержки и масштабирования:

* `tests/` — директория с тестовыми сценариями (например, `elements_test.py`).

* `pages/` — классы страниц, описывающие методы взаимодействия с веб-элементами (`base_page.py`, `elements_page.py`).

* `locators/` — локаторы для поиска элементов на веб-страницах (`element_page_locators.py`).

* `generator/` — скрипты для автоматической генерации рандомных тестовых данных с использованием библиотеки Faker (`generator.py`).

* `data/` — файлы хранения статических тестовых данных и дата-классов (`data.py`).

* `conftest.py` — фикстуры Pytest для конфигурации тестов (например, инициализация драйвера).

## Панель управления

* **Тесты:** В проекте реализованы UI-тесты (например, тесты поиска данных в таблицах по ключевому слову и работа с веб-элементами).

* **Баги:** *(Здесь вы можете оставить ссылку на ваш баг-трекер, например, доску в Trello, Jira или раздел Issues прямо в GitHub)*.

* **Allure Report:** Интегрирована система создания наглядных отчетов о результатах прохождения тестов.

## Окружение и запуск

### 1. Клонирование репозитория

Склонируйте проект на свой локальный компьютер и перейдите в папку проекта:

```
git clone https://github.com/MihailPOP123/automation_qa.git
cd automation_qa

```

### 2. Установка зависимостей

Так как проект использует пакетный менеджер **Poetry**, для установки всех необходимых библиотек в виртуальное окружение выполните команду:

```
poetry install
```

### 3. Запуск тестов

Для базового запуска всех тестов используйте команду:

```
poetry run pytest
```
